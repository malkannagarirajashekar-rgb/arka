# V63.0 Screenshot Analysis

Reviewed all PNG captures and JSON diagnostics/button inventories in `arka-screenshots32tests.zip`.

## User-visible findings
- Tenant User light desktop/mobile used a green-tinted page surface and dark hero treatment because its root is `.workspace-page`, while several light overrides targeted only `.workspace-shell`.
- Tenant Admin light desktop/mobile had a visually heavy dark/gradient Sign out treatment and a low-contrast welcome heading caused by the long cascade of historical theme overrides.
- Super Admin light desktop had the same dark/boxed Sign out treatment.
- Public light captures showed blue/green mixed neutrals and the Principle display word clipped to `CONTE` rather than `CONTEXT`.
- Login light retained a gradient primary action even though the requested visual language is now a restrained blue system.
- Theme controls were still visually card-like in some historical selectors.

## V63.0 source fixes
- Added a final semantic light-theme authority for `.workspace-page`, `.workspace-shell`, `.admin-shell`, `.arka-flow` and `.arka-access-page`.
- Added explicit light styling for Tenant User surfaces and Tenant Admin welcome content.
- Removed gradient backgrounds from interactive controls and made sign-out/theme controls flat/embedded.
- Added Principle width/overflow rules and responsive sizing.
- Added Playwright assertions for these contracts.
