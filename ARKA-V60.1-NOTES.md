# ARKA V60.1 — Kinetic Gradient UI

This revision keeps the existing application/database/authentication functionality intact and changes the visual interaction system.

## Included
- Full-screen drag-to-enter ARKA security perimeter on the public landing page.
- Original ARKA copy/brand language; no Pinnacl assets or source code copied.
- Editorial geometric section reveals using clip-path/transform rather than opacity-only scroll reveals.
- Interactive Context field with orbiting relationship geometry.
- Large gradient contact footer and back-to-top action.
- Route-level page transition for public and application routes.
- Shared navy/black/green gradient language extended into Admin, Tenant Admin, Login, loading states and onboarding surfaces.
- Reduced-motion fallback.
- Existing Supabase, role management, onboarding and admin functionality left untouched.

## Reference approach
The interaction direction is informed by the requested Pinnacl experience: strong full-screen gradients, gesture-led entry, large editorial typography, geometric transitions and a strong closing contact/footer surface. The implementation is original ARKA UI rather than a copy of Pinnacl's code or assets.
