ARKA — START HERE
=================

1. Keep this .env file (already restored from the original Arka project).
2. npm install
3. Run the existing Arka schema/migrations in Supabase.
4. IMPORTANT: run migrations/004_auth_access_context.sql after the identity/RBAC schema.
5. npm run dev
6. Open http://localhost:5173

LOGIN FLOW
----------
- Supabase handles email/password authentication.
- After successful login Arka resolves the user's role and routes automatically.
- SUPER_ADMIN -> /admin
- TENANT_ADMIN -> /tenant (or /onboarding when onboarding is incomplete)
- TENANT_USER -> /app
- A newly registered user with no organization membership -> /onboarding

REFERENCE ONBOARDING
--------------------
The organization setup is the brother's reference flow:
01 Initial Security Profile
02 Technology Environment
03 Security Stack
04 Security Priorities

On completion Arka creates/activates the tenant and its default security workspace.

If you change Supabase projects, replace the VITE_SUPABASE_URL and
VITE_SUPABASE_ANON_KEY values in .env with the new project's public values.
