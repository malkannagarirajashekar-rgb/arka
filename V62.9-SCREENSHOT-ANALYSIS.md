# V62.9 Screenshot Analysis

The supplied screenshot set was reviewed as a user-facing visual QA artifact, not only as a selector test.

## Findings

1. Public light mode was incomplete: the page background was light while Context, Guardian Gate and Contact retained dark/navy component surfaces.
2. The visual mismatch made those sections appear like separate applications embedded in the landing page.
3. The public theme toggle was visually boxed while the surrounding navigation was intentionally minimal.
4. Tenant Admin screenshot captures exposed a separate shell/capture concern; the QA flow now targets the protected main scroll container and validates the actual shell geometry.
5. The Tenant Admin Playwright assertion incorrectly treated inherited heading color equality as a failure. Inherited color is valid CSS behavior; the assertion now checks rendered geometry/readability instead.

## V62.9 intent

The light theme is now treated as a complete visual mode. Blue remains the ARKA accent language, but large surfaces are light and continuous with the page instead of dark blue blocks.

## Additional user-supplied screenshot findings

- 04 Context: the `NOW` relationship label was visibly clipped at the top of the visualization because the absolute relationship nodes had no deliberate placement anchors. V62.9 now places all five relationship labels inside the graph bounds on desktop and mobile.
- 07 Guardian Gate: the dark blue panel read as a separate block against the pale light-theme page. It is now a light surface with restrained blue grid detail.
- 08 Contact: the dark footer island had the same continuity problem. It is now a light footer surface with dark editorial typography and blue accent action.
- Theme toggle: the square bordered control was visually heavier than the surrounding navigation. It is now a small circular, borderless control.
- Tenant Admin: the supplied capture showed a large empty vertical region before the workspace content. The shell now uses a single fixed-sidebar/scrolling-main coordinate model to avoid competing flex/fixed geometry and misleading full-page capture behavior.
