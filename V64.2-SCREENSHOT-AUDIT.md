# ARKA V64.2 — Screenshot Audit + Layout Corrections

## Source reviewed
- V64.1 source ZIP
- `arka-screenshots(5).zip` including desktop/mobile, light/dark, after-scroll captures and element diagnostics
- Current `Workspace.tsx`, `TenantAdmin.tsx`, `Home.tsx`, `TempleScene.tsx`, and the final CSS cascade

## Corrections

### Tenant User
- Removed the second coordinate system that was causing the large empty gutter between the fixed rail and workspace content.
- Main content now starts directly after the fixed rail and uses the full available column.
- Removed the unnecessary boxed treatment from the welcome area.
- Reworked the Sanctum/Guardian strip into a seamless composition instead of nested cards.
- Increased the compact Guardian stage and moved top/bottom nodes inward so all six relationship nodes remain contained.
- Light theme now removes the dark sign-out slab and keeps the sidebar continuous with the page surface.

### Tenant Admin
- Kept the fixed rail/main coordinate system explicit and removed competing content centering.
- Light theme receives the same no-gradient control contract and a transparent sign-out area.
- Guardian context nodes are kept inside their visualization bounds.

### Public Home
- Guardian Gate is now a section-level composition, not a large rectangular card.
- 04 Context receives explicit width/height containment so the visualization and relationship nodes cannot clip at the section boundary.
- Context node positions are inset for desktop and mobile.
- Interactive buttons are solid ARKA blue; decorative gradients remain allowed only on non-interactive visual elements.

### All authenticated/public controls
- Final CSS contract removes gradient fills from interactive buttons, action controls, sign-out controls, and theme controls.
- Decorative gradients on backgrounds, diagrams, glows, and non-interactive visuals are intentionally retained.

## QA additions
- Protected desktop geometry now verifies that content begins immediately after the rail rather than relying on a screenshot impression.
- Added checks for Tenant User seamless welcome/Guardian composition and minimum Guardian stage height.
- Added checks that all six Guardian nodes stay inside the compact visualization.
- Added explicit light-theme sign-out transparency checks.
- Added public Context and Guardian Gate containment checks.
